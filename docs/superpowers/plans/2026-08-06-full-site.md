# PTL Full Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the six-page OUI-inspired PTL site in `full-site/` with a shared stylesheet, keeping the root coming-soon page untouched.

**Architecture:** Plain static HTML pages sharing one `styles.css`. Design tokens, atmosphere layers (grain/vignette), masthead/nav, footer and section components are defined once in the stylesheet; each page composes them. No build tooling; one tiny inline script per page for the mobile nav toggle.

**Tech Stack:** HTML5, CSS (custom properties, grid, clamp), Google Fonts (Bodoni Moda, Newsreader, Tiro Devanagari Hindi, Courier Prime). Vanilla JS ≤ 10 lines (nav toggle only).

## Global Constraints

- Palette/tokens copied verbatim from root `index.html`: `--ink:#0A0908`, `--ink-lift:#131110`, `--paper:#F2EDDC`, `--ember:#D08A3E`, `--gold:#E3B23C`, plus the paper-alpha steps.
- Same four Google Fonts link tag as root `index.html`.
- Root `index.html` and `README.md` are NOT modified.
- All invented content (team bios, testimonial quotes, TBA dates) must be visibly marked placeholder — bracketed `[Name]` or a `PLACEHOLDER` mono label — never presented as fact.
- Real facts only from project memory: PTL profile, Baithak, KSR details, socials.
- Nav (same order on every page): Home · Gatherings · Baithak · Ruhdaari · Collective · Collaborations. Current page gets `aria-current="page"` + ember underline.
- Footer (every page): Instagram, Facebook, Ruhdaari Instagram links + colophon, as in root page.
- `prefers-reduced-motion` honored; `:focus-visible` outline; skip-to-content not required (single-main pages).
- KSR CTAs say "Register" (contribution-based, registration-only) — never "Buy Tickets".
